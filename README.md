# Port Azahar 3D

Port Azahar 3D is an original real-3D open-world crime game built with Three.js for the make.fun gta6-01 competition. Play as wheelman Dario Venn across five distinct districts (Docks, Neon Mile, Old Town, Marina, and The Hills), taking on high-stakes jobs for fixer Marisol Kane, dodging the police, driving cars, and exploring a fully realized 3D city with day/night lighting cycles and procedural textures.

## Features

- **Real 3D Open World**: WebGL rendering via Three.js with perspective cameras, extruded buildings with lit night windows, water planes, and dynamic lighting.
- **Crime & Action Systems**: 5-mission story campaign, vehicle driving physics, on-foot movement, combat, wanted levels (0–5 stars), police pursuit AI, and interactive HUD with minimap.
- **Staged Cinematic Shots**: Deterministic staging for automated screenshot capture showcasing title aerial, traffic drive, police chase, and neon night views.
- **Zero-Dependency Static Delivery**: Runs entirely offline in desktop Chrome from static files with WebAudio synthesized sound effects.

## Run It

1. Start the local static server:
   ```bash
   node serve.ts --port 8080
   ```
2. Open your browser at:
   ```
   http://localhost:8080
   ```
